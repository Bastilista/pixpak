What you're not doing anymore

no-01

Local environment setup

Codespaces builds the container from .devcontainer/ the moment it opens. Same environment, every time, for every contributor.

no-02

"Works on my machine"

Dependencies, extensions, and ports are declared in code and versioned in the repo — not tribal knowledge in someone's head.

no-03

Onboarding docs that rot

New contributor clicks "Open in Codespaces." That's the onboarding doc now, and it can't go stale.

/* quickstart */

Three commands, then you're building

01

Open in Codespaces

From the repo, click Code → Codespaces → Create codespace on main.

02

npx serve .

Or just open index.html with the Live Server extension — both are preconfigured.

03

Edit & save

The forwarded port auto-refreshes in your browser preview. Ship when it looks right.
